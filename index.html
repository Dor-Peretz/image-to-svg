Image to SVG

Drop in a photo or logo. The app converts it to black and white, traces the shape, and exports a clean SVG you can scale forever.

Drop an image here or click to choose a PNG, JPG, or WebP

Print size

Type the width you want. Height is calculated from the image ratio so it will not stretch.

Add threshold zones

  1. Click Add zone

Edit SVG

Click a part to select it. Shift-click to select more. Delete leftover blobs, then change fill, stroke, or outline.
